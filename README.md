---

## 🚀 Currently Building

### [Cobble](https://github.com/cobble-project/cobble) · Rust
A high-performance **LSM-based embedded key-value store** for distributed systems and standalone apps — think RocksDB with distributed superpowers:

- Hybrid local/remote object storage (S3, OSS, …)
- Distributed global snapshots & remote compaction
- Key-value separation, TTL, hot/cold tiering
- Schema evolution & multi-version snapshots
- Multi-language bindings (Java supported)

### [Cobble Flink](https://github.com/cobble-project/cobble-flink) · Java
A unified storage layer for Apache Flink that makes **state and sink data disaggregated, observable, and consumable**:

- Flink **state backend** + **SQL source/sink**
- Disaggregated state with high performance and fast rescaling
- Web monitor to inspect checkpoint & sink snapshots without touching running jobs

### Rivus · Rust · *private, in the works*
A stateful stream processing engine focused on **rapid scaling, rolling updates, and record-level observability** — stay tuned. 🔮
